Built for the cases that break naive APIs.

The happy path is easy. This project focuses on the harder guarantees behind it: exact money arithmetic, consistent writes under failure and predictable behaviour when clients retry.

Integer money

Every amount is stored in pence, eliminating floating-point rounding errors.

Atomic writes

Debit and credit either commit together or roll back together.

Idempotent retries

Repeated requests return the first transfer instead of moving money twice.

Concurrency control

Deterministic row locks prevent simultaneous overspending and deadlocks.
